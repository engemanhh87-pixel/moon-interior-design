# moon للتصميم الداخلي

الدفعة الأولى: صفحة رئيسية متجاوبة بالعربية والإنجليزية، خدمات، إلهام بصري، باقات أولية، ونموذج معاينة طلب استشارة.

## التشغيل

`node server.cjs`

ثم افتح http://127.0.0.1:3000 . لا توجد تبعيات خارجية.

## حدود المرحلة

الصور المرفقة مراجع للهوية وليست أعمالًا موثقة للاستوديو. النص التعريفي مسودة للمراجعة. الأسعار وبيانات التواصل غير معتمدة. النموذج يعرض البيانات محليًا فقط ولا يحفظها أو يرسلها؛ لا يوجد حجز فعلي أو دفع في مرحلة الواجهات.

## الدفعات التالية

صفحات الخدمات وتفاصيلها، معرض المشاريع الفعلية، تفاصيل الباقات ومسار شراء الخدمة، اختيار مواعيد الاستشارة، ثم الباك إند وقاعدة البيانات ولوحة الإدارة وفق الخطة المرحلية.
